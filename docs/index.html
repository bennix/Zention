本地笔记 · 0.1.14

一页纸，
写到可以同步。

公式、图片、代码、表格和数据库先留在你的电脑上。表格可以加减行列、合并单元格。数据库的行仍是一篇笔记。建库、改属性和筛选都可以用现成的指令模板，让 AI 先起草。要对齐时，先选哪一边覆盖哪一边，再和 GitHub 同步。

macOS已公证 DMG Windows64 位安装包 Linux DEBx64 Linux DEBarm64 Linux RPMx64 Linux RPMarm64

macOS 安装包使用 Developer ID 签名，并经过 Apple 公证。笔记默认只在本机，密钥和 GitHub token 也只加密保存在这台电脑上。

这一版能做什么

先写在本机

每一页都是 Markdown，存在这台电脑的应用数据里。不登录也能写。公式、图片、代码和正文在同一页，导出时可以另存为 Markdown 或 PDF。界面有简体中文，也可以换成繁体、英文、日文和其他语言。

斜杠就能插入

输入 / 可以插入标题、列表、待办、引用、表格和分割线。代码块会按语言上色。Mermaid 写完后画成图。本地图片和网络图片都能放进来。设置里可以扫描 assets：会显示读笔记和核对图片的进度与速度，未使用的本地图片会移到废纸篓，而不是直接删掉，之后还能从废纸篓恢复。

Markdown 表格跟着光标走

光标在表格里时，工具条浮在这张表的上方；上面放不下就改到下方，滚动时跟着走。可以在上方或下方加行，在左侧或右侧加列，也可以删掉当前行或当前列。按住 Shift 点选相邻单元格后，可以合并；已经合并的格子可以再拆开。表头行可以开关。列宽可以拖。整张表可以删：点工具条上的「删除表格」，或先点选整张表再按 Delete。

数据库的每一行仍是一篇笔记

侧栏可以新建数据库。每一行是一篇独立页面，点「打开」就回到完整正文。属性可以是文本、数字、单选、多选、勾选或日期。同一份数据有表格和看板两种看法。看板按一个单选属性分列，把卡片拖到另一列就会改掉那个值。筛选支持包含、等于和为空，只作用在当前视图。不需要的行可以在表格末尾或看板卡片上删除。

建库和筛选可以让 AI 起草

新建数据库时可以先选一个写好的指令：任务看板、阅读清单、客户跟进、会议纪要或习惯打卡。指令可以改，再生成标题、属性和示例行；也可以直接建一个空白库。打开已有的库之后，AI 可以调整属性、只补全空着的字段、生成示例行，或按你的描述改筛选。筛选条上还有单独的「AI 筛选」。模型返回的结构会先按现有属性规则检查，对不上的内容不会写入。

公式可以改，也可以认

行内公式和公式块点开就能改。也可以贴一张公式截图，让它写成公式；或者用一句话描述，让 AI 把公式写进笔记。

拖块之前先看到位置

抓住左侧把手拖动时，松手之前会画出插入线。不按修饰键是移动。按住 Ctrl 或 Option 是复制到那条线，线上会出现加号。复制不会删掉原来的块。

侧边栏收成文件夹

把一条笔记拖到另一条上面，它就变成子笔记。接收它的那一条会标成文件夹，侧边栏可以展开。分组把笔记归到一组，标签用来筛选。这些结构会和正文一起同步。

笔记之间可以跳

链接可以指向另一篇笔记，点一下就打开。向 AI 提问时，用 @ 带上已有笔记，它会连同那一页一起看。选中一段后可以润色、缩短、扩写或翻译，也可以按这段在上方或下方插图。

同步前必须选边

和 GitHub 同步前会问方向：远程覆盖本地，或本地覆盖远程。数据库的属性、视图、筛选和每一行的字段写在页面标记里，会跟着这一页一起走。同步上去的数据库文件里还有一张可读的表，拉回来时以标记为准，不会把那张表写进正文。可以新建私有仓库，也可以绑定已有仓库。Token 需要 repo 权限，只加密留在本机。登录可以用网页 token，也可以用本机的 gh。

更新跟着代理走

0.1.13 起，检查更新和下载安装包使用设置里保存的代理。没填时会尝试系统代理，留空则直接连接。macOS 的「Zention」菜单、Windows 和 Linux 的「更新」菜单里都有「检查更新」。下载完成后，菜单和设置里都可以「重启并升级」。

代理管的是出门的请求

同一条代理地址同时用于 AI 对话、生图、GitHub 同步和检查更新。支持 HTTP 和 SOCKS，例如 127.0.0.1:7890。打开设置时会尝试填入系统代理，保存之后才生效。笔记本身不会因为开了代理就被上传。
