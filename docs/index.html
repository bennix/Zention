这一版能做什么

写作与版面

先写在本机

每一页都是 Markdown，存在这台电脑的应用数据里。不登录也能写。公式、图片、音视频、代码和正文在同一页，导出时可另存为 Markdown 或 PDF。界面有简体中文，也可换成繁体、英文、日文和其他语言。

斜杠就能插入

输入 / 可插入标题、列表、待办、引用、表格、分割线、目录、分栏、折叠标题、标签页和按钮。代码块按语言上色；Mermaid 写完后画成图。本地图片、网络图片、音频和 MP4 都能放进来。

AI 辅助建 Markdown 表

斜杠选「AI 表格」，用自然语言说明列名和内容，模型只返回一张可用的 Markdown 表并插入当前位置。写任务清单、对照表、周计划时不必手搓表头。

Markdown 表格跟着光标走

光标在表格里时，工具条浮在表上方；放不下就改到下方，滚动时跟着走。可上下加行、左右加列，也可删行删列。按住 Shift 点选相邻单元格后可合并，已合并的可再拆开。表头可开关，列宽可拖。整张表可用工具条删除，或先点选再按 Delete。

折叠标题可改、字号跟级别走

折叠标题 1 / 2 / 3 的标题可直接点进输入框修改。展示字号分别对应正文 H1、H2、H3。左侧箭头只负责展开与收起，不会和改标题抢操作。

目录、分栏、标签与按钮

目录块可列出本页标题，点链接会滚到正文并短暂高亮；也可用 AI 根据正文补大纲。两栏或三栏分栏、折叠块、标签页把长笔记拆开。按钮可设文案，并指定跳转到其他笔记、外链或本页某个标题；未设链接时仍跳到同页第一个标题。

公式可以改，也可以认

行内公式和公式块点开就能改。也可贴公式截图让它写成公式，或用一句话描述，让 AI 把公式写进笔记。

音视频就地播放

斜杠插入音频或视频后，文件拷进工作区的 media 目录，正文里用原生控件播放。路径写在笔记里，和图片一样可随 GitHub 一起走。

数据库

每一行仍是一篇笔记

侧栏可新建数据库。每一行是一篇独立页面，点开就回到完整正文。属性可以是文本、数字、单选、多选、勾选、日期或图片。图片属性可选本地图，画廊和看板会用首个图片属性做封面。

多种看法，一张数据

同一份数据可在表格、看板、画廊、列表、日历、时间线之间切换。看板按单选属性分列，拖卡片就会改属性。日历和时间线按日期属性排布。还可做柱状、折线、环图和数字汇总，按分组属性聚合计数或求和。

建库和筛选可以让 AI 起草

新建时可选任务看板、阅读清单、客户跟进、会议纪要或习惯打卡等模板；也可空白开库。已有库可用 AI 调整属性（含图片属性）、补空字段、生成示例行，或按描述改筛选。筛选支持包含、等于和为空。模型返回的结构会先按规则检查，对不上的不会写入。

组织、同步与更新

拖块之前先看到位置

抓住左侧把手拖动时，松手前会画出插入线。不按修饰键是移动；按住 Ctrl 或 Option 是复制到那条线，线上会出现加号。

侧边栏收成文件夹

把一条笔记拖到另一条上面，它就变成子笔记。接收方会标成文件夹。分组和标签用来归类筛选，结构和正文一起同步。

笔记之间可以跳

链接可指向另一篇笔记。向 AI 提问时用 @ 带上已有笔记。选中一段后可润色、缩短、扩写或翻译，也可按这段在上方或下方插图。

同步前必须选边

和 GitHub 同步前会问方向：远程覆盖本地，或本地覆盖远程。数据库的属性、视图、筛选和字段写在页面标记里，跟这一页一起走。同步上去的库文件里还有一张可读表，拉回时以标记为准。图片在 assets，音视频在 media，两边都会推送与拉取。可新建私有仓库或绑定已有仓库。Token 需要 repo 权限，只加密留在本机。

未使用的本地文件可清到废纸篓

设置里可扫描 assets 与 media：显示读笔记、核对文件的进度与速度。未引用的图片和音视频会移到废纸篓，而不是直接删掉。

更新跟着代理走

检查更新和下载安装包使用设置里保存的代理。没填时会尝试系统代理。macOS 的「Zention」菜单、Windows 和 Linux 的「更新」菜单里都有「检查更新」。下载完成后可「重启并升级」。

代理管的是出门的请求

同一条代理同时用于 AI 对话、生图、GitHub 同步和检查更新。支持 HTTP 和 SOCKS。笔记本身不会因为开了代理就被上传。
